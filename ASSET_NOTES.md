# Current Studio Roast branding

The owner replaced the original cursive logo with the SR monogram, coffee branch and STUDIO ROAST name. Only the updated artwork is used in this website and its current PDFs.

Original, unchanged owner artwork: `docs/assets/studio-roast-logo-original-v2.jpeg`.
Prepared transparent white texture: `docs/assets/studio-roast-logo-led-v2.png`.
Method: built-in ImageGen tool. The WebGL shader renders this as white rear LED lettering and dark recessed engraving on the original operator-facing walnut. Final sign and engraving artwork should be prepared from the owner's original reference.

Prompt used:

> Use case: background-extraction. Edit target: the NEW supplied Studio Roast logo: large serif S on left, fine botanical coffee branch vertically in centre, large serif R on right, spaced uppercase STUDIO ROAST beneath. Produce ONLY this exact complete logo on true transparent alpha. Preserve the precise monogram, branch drawing, leaf and berry detail, proportions, and typography. Convert all original black strokes to luminous white with only a faint tight white LED halo; remove all white background and black outer image border. Keep the exact text "STUDIO ROAST". No cursive text, no old script logo, no circle, no invented elements, no sign backing. Flat orthographic artwork, tightly framed around the complete mark with a small transparent margin on all sides. This alpha texture will be mapped onto a stainless cart rear as white LED and reused as dark etched branding on walnut, so preserve all small internal transparent spaces in the artwork.

All cart geometry and measurements are code-based. PDF view images were exported from the same interactive model.
